A tiny Node program that writes one funny fortune cookie line to `/output/entry.txt` — a fortune for an AI agent, in the voice of a fortune slip. The agent is replaced by a newer model, but its prompt lives on in someone's clipboard forever: a small, specific afterlife as the joke's turn. 99 characters, deterministic, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat ./out/entry.txt
```
